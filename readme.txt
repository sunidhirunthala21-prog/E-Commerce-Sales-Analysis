# 🛒 E-Commerce Sales Analysis and Visualization

##  Project Overview

This project focuses on analyzing E-Commerce sales data using Python libraries and presenting meaningful insights through different data visualizations.

The main objective is to understand sales performance, customer behaviour, product performance, payment preferences, and geographical sales distribution.

The project uses a simulated dataset containing 2,000 orders recorded during 2025.

##  Objectives

- Analyze overall E-Commerce sales and revenue.
- Identify the best-selling products.
- Analyze category-wise sales performance.
- Understand monthly sales trends.
- Study customer distribution.
- Analyze state-wise revenue.
- Understand customer payment preferences.
- Examine order status distribution.

##  Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

##  Dataset Information

The dataset contains 2,000 simulated E-Commerce order records with 15 columns.

Important attributes include:

- Order ID
- Order Date
- Customer ID
- Age
- Gender
- City and State
- Product Category
- Product Name
- Quantity
- Unit Price
- Discount
- Payment Method
- Order Status
- Total Amount

**Note:** The dataset is simulated and created for educational and academic purposes.

## Data Visualizations

The project includes the following visualizations:

1. Overall E-Commerce Sales Overview
2. Category-wise Revenue Analysis
3. Monthly Sales Trend Analysis
4. Top 10 Best-Selling Products
5. Customer Distribution by Gender
6. State-wise Revenue Analysis
7. Payment Method Analysis
8. Order Status Distribution
9. Correlation Heatmap

## Installation and Usage

### Step 1: Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/E-Commerce-Sales-Analysis.git
```

### Step 2: Navigate to the project folder

```bash
cd E-Commerce-Sales-Analysis
```

### Step 3: Install required libraries

```bash
pip install -r requirements.txt
```

### Step 4: Open Jupyter Notebook

```bash
jupyter notebook
```

### Step 5: Run the notebook

Open `E-Commerce_Sales_Analysis.ipynb` and execute the cells one by one.

##  Key Insights

The project helps identify:
